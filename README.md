# jinzihao-database-extension

If this extension is installed and enabled, jinzihao Beijing bus database will be able to display the bus model.

However, due to the fact that most mobile browsers do not support third-party extensions, the application scope of this extension is extremely limited.

This extension is entirely based on local data and front-end interface modifications, and does not affect the access speed or website operation (although the loading speed may be affected by computer and browser performance). It also does not collect any of your operation and access records.

When using this extension, please comply with relevant Chinese national laws and regulations as well as the user guidelines of jinzihao Beijing bus database.
